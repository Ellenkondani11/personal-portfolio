Project 1: Sitting at First Line of Sight

Project 2: Inventory Management System

Problem the Project Intends to Solve
Stock management previously relied on paper ledgers. Multiple staff members had inconsistent records, reorders depended on individual memory, and unauthorized inventory adjustments could not be traced or audited.

Engineered a full stack web platform that records product receipts, warehouse transfers, and outbound orders through an append only audit ledger. Built automated low stock alert thresholds, multi role permissions, and graphical monthly inventory turnover analytics.

Key Architectural Highlights:
  • Append only transaction ledger ensuring zero data loss
  • Real time low stock threshold calculations and reorder cues
  • Granular permissions separating store clerks from auditing supervisors

Project 3: High Reliability UDP File Sharing Application

Problem the Project Intends to Solve
Transferring substantial file assets between local workstations in district institutions often fails due to absent or costly internet access. Standard UDP network transfers drop packets without acknowledgment, resulting in silent data corruption.

Designed and implemented a custom peer to peer network protocol on top of raw UDP sockets. Features sequence numbered chunking, a sliding window flow control mechanism, selective packet retransmission, and cryptographic SHA 256 file integrity validation upon reassembly.

Key Architectural Highlights:
  • Reliable transport semantics layered cleanly over lightweight UDP
  • Cryptographic SHA 256 hash comparison proving bit perfect delivery
  • Real time throughput metrics and packet loss diagnostic terminal meters
