Multimedia Tools Assignment: First Line of Sight

Elle Agri Tech Links (EATL) Corporate Visual Identity and Brand System

A complete corporate visual identity and digital design project developed for the Multimedia Tools and Applications course (Module Code: 351cs3203). EATL connects agricultural communities and agribusinesses to modern smart farming, irrigation methods, and digital record keeping.

  • Problem Addressed: Fragmented agricultural information, lack of unified digital presence, and limited farmer access to modern technology.
  • Design Assets Created: Full colour logo, monochrome symbol, corporate stationery, business cards, vehicle branding, billboard advertisement, and A3 promotional poster.
  • Multimedia Tools: Canva graphic production platform, custom typography palettes (Montserrat and Poppins), and vector illustration workflows.

Inventory Management System

Problem Solved
Manual paper ledgers caused discrepancy in stock records, reorders depended on human memory, and no audit trail existed for lost goods.

Engineered a relational web application that tracks products, suppliers, and batch movements through an append only database architecture. Includes automated threshold notifications and role based clearance.

UDP Reliable File Sharing Application

Problem Solved
Moving heavy assets across local district networks should not require expensive internet bundles, but naive UDP protocol drops packets without detection.

Engineered a high throughput socket application with a sliding window transmission engine, selective retransmission for dropped chunks, and end to end SHA 256 checksum verification in a dual pane terminal screen.
